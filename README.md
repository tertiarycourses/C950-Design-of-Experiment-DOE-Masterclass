## About the course

Engineers and researchers learn to design fewer, better experiments: frame a measurable question, choose factors and levels, generate full factorial, fractional factorial, Plackett-Burman, response-surface, mixture and Taguchi designs in NovaDOE, then analyse the evidence in Excel and recommend confirmation runs. The slide deck is visual and concept-led; detailed procedures live in the Learner Guide and each activity folder.

## Learning outcomes

- LO1: Analyse process interactions to characterise key factors influencing performance in Design of Experiments.
- LO2: Select suitable factorial DoE projects by evaluating relevant performance metrics.
- LO3: Define the scope and execute fractional factorial DoE projects using problem-solving techniques.
- LO4: Evaluate the effectiveness of DoE projects and recommend follow-up actions.

## Topics covered

1. Fundamentals of Design of Experiments — questions, variables, variation, hypothesis tests and one-way ANOVA
2. Factorial Design of Experiments — main effects, interactions, regression, ANOVA, blocks and confounding
3. Fractional Factorial and Screening Designs — generators, aliases, resolution, Plackett-Burman and sequential experimentation
4. Screening, Modelling and Optimising DoE — response surfaces, CCD, Box-Behnken, mixtures and Taguchi robustness

## Using NovaDOE

Open [NovaDOE](https://alfredang.github.io/novadoe/), select the method named in the activity, define factors and feasible limits, generate and verify the design, export it as `learner-design.csv` into the activity folder, then follow the Learner Guide to join the mock response and interpret the evidence.
